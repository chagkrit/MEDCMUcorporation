## อัปเดตเมื่อมีข้อมูลใหม่
1. วางไฟล์ xlsx ใหม่ใน `../ZocialEye/` (ชื่อไฟล์ต้องมีคำว่า `Social Metric`, ` Owned ` หรือ ` Earned `; ตั้ง `MEDCMU_ZE_DIR=/path` ได้หากอยู่ที่อื่น)
2. `python3 build_monthly.py`
3. `python3 verify_monthly.py` → ต้องเห็น `mismatches: 0`
4. `python3 -m unittest discover -s tests`

## กติกาตัวเลข
- **เลือกไฟล์:** เดือนที่มีหลายไฟล์ทับกัน ใช้ไฟล์ที่ `Generated At` ใหม่สุดของแต่ละประเภท (Owned/Earned) ตัดสินด้วยเวลาในไฟล์ ไม่ได้กำหนดรายเดือน (ม.ค.–มิ.ย., ส.ค., ก.ย. = Social Metric; ก.ค./ต.ค. = Owned export)
- **สถานะเดือน:** ครบเดือน / ข้อมูลบางส่วน / ไม่มีข้อมูล · ช่วงวันที่สิ้นสุดถูกตัดที่ "วันก่อนวันที่ไฟล์ถูกสร้าง" (ต.ค. = 1–15) · เดือนไม่มีข้อมูล (มิ.ย.) ไม่ประมาณค่า เป็นช่องว่างในกราฟ
- **% เทียบเดือนก่อน** แสดงเมื่อทั้งสองเดือนที่ติดกันครบเดือนและมาจากไฟล์ประเภทเดียวกันเท่านั้น (ถ้าเดือนก่อนเป็น 0 แสดง “▲ จาก 0”) · เดือนที่เลือกใช้ร่วมกันทุกหน้าที่เป็นรายเดือน
- **สัดส่วน engagement ของ 1/3 โพสต์บนสุด** นับเฉพาะโพสต์ที่มีข้อความ (ประชากรเดียวกับรายการโพสต์เด่น) · **ยอดรวมข้ามแพลตฟอร์ม** ระบุจำนวนแพลตฟอร์มที่มีข้อมูล (เช่น จุฬาฯ 4/5 เพราะไม่มี YouTube)
- **โพสต์ที่นับ** = แถวที่มีข้อความ · **engagement** = คอลัมน์ Engagement ในไฟล์ (X: Reply→comment, Repost+Quote→share) · ค่าที่หายเป็น "ข้อมูลไม่เพียงพอ" ไม่ใช่ 0
- **YouTube engagement ในไฟล์ Social Metric** คอลัมน์ Engagement เป็น 0 ทุกแถวแม้มี Like/Comment ตัวอ่านไฟล์จึงคำนวณ Engagement = Like + Comment (เฉพาะชีต YouTube ที่ทั้งชีตเป็น 0; ในไฟล์ Owned export ค่านี้ตรง Like + Comment ทุกแถว 173/173) และแจ้งไว้ในหน้า "คุณภาพข้อมูล"
- **ยอดดู** รวมเฉพาะ IG + TikTok + YouTube (Facebook ในไฟล์ Social Metric ไม่มีคอลัมน์ View, X ไม่มียอดดู)
- สองไฟล์ที่ทับกันนับไม่เท่ากัน (ดูตารางส่วนต่างในหน้า "คุณภาพข้อมูล") เส้นแนวโน้มอาจกระโดดตรงเดือนที่เปลี่ยนไฟล์ จึงแสดงชื่อไฟล์ใต้ชื่อเดือน
- ไม่มี reach / impression / click / LINE OA / ผู้ติดตาม

## หน้าตา
- Swiss/minimal หนาแน่น (ต่อจากเวอร์ชัน 2026-10-05): ฟอนต์ Inter + Noto Sans Thai, แถบตัวกรองแบรนด์ติดบน (ค่าเริ่มต้น MEDCMU อย่างเดียว; การ์ดเทียบแบรนด์ในหน้าภาพรวมแสดงครบ 4 แบรนด์เสมอ), ธีมมืด/สว่าง, โหมดนำเสนอเต็มจอ (ลูกศรซ้าย/ขวา, Esc ออก), พิมพ์/บันทึก PDF สลับเป็นธีมสว่างอัตโนมัติ
- สถานะเดือนสื่อด้วยข้อความ + รูปจุด (ทึบ/กลวง/ไม่มี) + ขอบเส้นประ ไม่พึ่งสีอย่างเดียว; สีแบรนด์ `--b-*` เป็นความหมายของข้อมูล ไม่ใช้กับตัวเมนู
